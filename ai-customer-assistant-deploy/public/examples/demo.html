Easy Integration

Add the AI Customer Assistant to your website with just a few lines of code:

<script> (function() { var script = document.createElement('script'); script.src = 'https://your-domain.com/widget.js'; script.dataset.widgetId = 'your-widget-id'; script.dataset.primaryColor = '#667eea'; script.dataset.position = 'bottom-right'; script.dataset.welcomeMessage = 'Hello! How can I help you today?'; document.head.appendChild(script); })(); </script>

Configuration Options

  • widgetId: Unique identifier for your widget
  • primaryColor: Main color theme (hex color)
  • position: Widget position (bottom-right, bottom-left)
  • welcomeMessage: Initial greeting message
  • apiUrl: Your API endpoint (optional)
